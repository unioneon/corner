# Product artwork

The cover was generated with the built-in OpenAI imagegen tool, using the
actual exported light/dark settings images and the original corner icon as
references. It is promotional artwork, not a raw screenshot.

The GitHub Social preview is a 1280×640 JPEG of this same approved poster,
exported at high quality by `scripts/brand-assets.ps1`. The README cover and
shared link cards therefore show the same design.
The supplied SF Pro files were available locally during typography rendering;
no font files are part of the published assets.

## Final imagegen prompt

Create a polished premium launch poster for an independent Windows utility named exactly "corner". Use case: ads-marketing. Asset: GitHub README hero / product poster. Wide landscape composition with a 2:1 aspect ratio if possible, high resolution. Reference image 1 is the REAL light settings UI; reference 2 is the REAL dark settings UI; reference 3 is the product's exact black logo. Preserve the recognizable logo and preserve the real native UI layout, text, proportions and controls; do not redesign it or invent widgets. The two long, low-profile settings windows should be the central product objects, floating at a gentle angle on a very restrained warm-white / silver background. A large satin electric blue #196EFE continuous-corner frame or ribbon echoes the way this app rounds the four corners of the display. Elegant hardware-quality product photography aesthetic, very soft shadows, immaculate typography, generous negative space, sophisticated editorial composition. NOT a laptop mockup, no Apple logos, no macOS, no people. Brand is monochrome with this one blue accent. Place the exact provided logo beside a large lowercase wordmark "corner" at upper left. Exact headline: "A softer edge to Windows." Small footer text: "Live preview  •  Light + dark  •  Native Windows". Keep text minimal, readable and spelled exactly. The dark UI and light UI are actual product evidence, not abstract fake UI. Use the original rounded window silhouettes with proper smooth alpha edges, black and white versions. The graphic should feel as carefully designed as an excellent small Windows utility. No badges, no star ratings, no invented claims about Apple hardware, no watermark.
